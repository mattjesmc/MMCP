This file was the **work list** for release 1: every item, its arbiter, its build record, and the
section letters (`A`, `B1`, `B2`, `D4`, `F8`, `J`, `K`, ...) that **86 files in this tree still cite
as provenance** - Java sources, tests, probes, `build.gradle` and the shim among them. It is 1,698
lines of decisions about what to build, and it is not something a consumer of the toolkit needs.

**It lives in the workbench's private archive repository** (`mcmodding-archive`, at this same path),
together with `TODO.md` and `docs/archive/TODO_SHIPPED.md`, which left for the same reason.

**This stub stays because deleting it outright would leave those 86 citations naming a document that
does not exist** - and a document naming something that is not there is the one defect this release
spent its last day removing (`RELEASE.md` section 3.1 and F7 record three instances of it). A
citation that resolves to this page tells you what it pointed at and where it went. That is worth one
file.

**What replaces it for a reader here:** `RELEASE.md` - the ledger the release was cut from. It says
what ships, what has been verified on the code that ships, and what is still open, and where a claim
rests on a log it names the log. Start there.
